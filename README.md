# Эмулятор командной строки

Практическая работа №1 по конфигурационному управлению, вариант 24.
Программа на Python 3.13 с окном на tkinter, которое ведёт себя похоже на
командную строку UNIX.

Сейчас сделаны этапы 1 и 2: окно с вводом команд, простой парсер, заглушки
команд, параметры командной строки и стартовый скрипт.

## Параметры

```
python src/main.py [--vfs PATH] [--script PATH]
```

`--vfs` задаёт путь к директории с VFS. Пока VFS не загружается, путь
только запоминается, а последняя часть пути показывается в заголовке окна.
Без параметра в заголовке будет `vfs`.

`--script` задаёт стартовый скрипт. Он выполняется сразу после открытия
окна, потом можно вводить команды вручную.

При запуске в окно и в консоль выводятся все параметры, например:

```
vfs: vfs/demo
script: (not set)
```

## Стартовый скрипт

Обычный текстовый файл в UTF-8, одна команда на строку. Комментарии как в
Python: всё после `#` до конца строки. Пустые строки пропускаются.

В окне видно и команду, и её вывод, как будто их ввёл пользователь. Если
команда завершилась с ошибкой, перед сообщением пишется номер строки, и
скрипт идёт дальше:

```
$ cd a b
script: line 7: cd: too many arguments
```

Если файла нет, будет `script: PATH: No such file or directory`. Команда
`exit` в скрипте закрывает эмулятор.

## Команды

`ls [args]` и `cd [dir]` пока заглушки: печатают своё имя и аргументы.
`cd` с двумя и более аргументами выдаёт `cd: too many arguments`.

`exit [code]` закрывает окно. Код должен быть числом, иначе будет
`exit: abc: numeric argument required`.

На неизвестную команду выводится `name: command not found`.

## Запуск

Windows:

```
run.bat --vfs vfs/demo --script scripts/start.txt
```

Linux:

```
sh run.sh --vfs vfs/demo --script scripts/start.txt
```

В папке `scripts/` лежат скрипты для проверки параметров, каждый в
вариантах `.bat` и `.sh`: `no_args`, `vfs_only`, `script_only`,
`all_args`, `bad_script` (скрипта нет) и `script_error` (ошибки в середине
скрипта, после них выполнение продолжается). Там же стартовые скрипты
эмулятора `start.txt` и `error.txt`.

## Пример

```
$ ls -l /home
ls -l /home
$ cd a b
cd: too many arguments
$ hello
hello: command not found
$ exit abc
exit: abc: numeric argument required
$ exit
```

## Структура

`src/commands.py` содержит парсер и команды, `src/script.py` выполняет
стартовый скрипт, `src/config.py` разбирает параметры. Они не зависят от
GUI и проверяются тестами. `src/gui.py` содержит окно, `src/main.py`
запускает программу.
